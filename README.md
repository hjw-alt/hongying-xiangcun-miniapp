# 红映湘村 · 湘潭红色村落数字文旅与文创助农计划

参赛项目「红映湘村」的完整实现，包含微信小程序、Go 后端服务与 Vue 内容管理后台。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `frontend/` | 微信小程序（6 个主板块 + 4 个二级页面） |
| `backend/` | Go 后端服务，提供 RESTful 接口与静态资源托管 |
| `admin/` | Vue 3 内容管理后台，构建产物由后端托管 |
| `tools/` | 配图与图标生成脚本 |
| `output/pdf/` | 项目企划书与生成脚本 |
| `legacy-miniprogram-pages/` | 早期纸影戏主题页面备份（已移出小程序包） |

## 小程序板块

1. 首页：轮播、快捷入口、村落、线路、故事、文创、助农与研学的聚合
2. 红文创：文创商城与助农转化入口，含 DIY 定制商品
3. 导览：红色村落地图、主题线路与村落详情
4. 红迹：数字故事列表与详情，含 AR 老照片
5. 研学：打卡任务、积分与打卡记录
6. 助农：合作农户、帮扶进度与湘村风物

## 下单流程

- 商品详情页支持「加入购物车」与「立即购买」两种方式，支持 DIY 定制的商品可先填写定制要求
- 购物车可勾选多件商品合并结算，支持修改数量与移除
- 结算页可选择已保存的收货地址，也可跳转到地址管理页新增
- 「我的」页面提供购物车与收货地址管理入口，并展示订单、打卡与积分

## 启动方式

```powershell
# 1. 启动 MySQL 后运行后端
cd backend
$env:MYSQL_DSN = "root:123456@tcp(127.0.0.1:3306)/shadowart_xiangtan?charset=utf8mb4&parseTime=true&loc=Local"
go run .

# 2. 后台前端（改动后需要重新构建）
cd ..\admin
npm install
npm run build
```

后端启动后：小程序接口在 `http://127.0.0.1:8080/api`，管理后台在 `http://127.0.0.1:8080/admin/`（账号 `hjw` / `123456`）。

微信开发者工具导入 `frontend` 目录即可运行小程序，需在「详情 - 本地设置」中勾选「不校验合法域名」。
