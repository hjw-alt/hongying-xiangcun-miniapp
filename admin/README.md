# 红映湘村 · 内容管理后台

基于 Vue 3 + Vite 的内容管理后台，由 Go 后端直接托管，用于维护小程序端的全部内容与订单。

## 访问方式

后端启动后访问 `http://127.0.0.1:8080/admin/`，默认账号 `hjw` / `123456`。

## 可维护模块

| 模块 | 说明 |
| --- | --- |
| 数据概览 | 村落、景点、线路、故事、商品、农户、任务、订单、打卡等总量 |
| 订单管理 | 查看文创与助农订单，修改发货状态（同步到小程序「我的订单」） |
| 首页轮播 | 小程序首页轮播图与跳转目标 |
| 红色村落 | 村落概况、历史脉络、荣誉与主题标签 |
| 村落景点 | 故居、纪念馆等点位的图文与坐标 |
| 红色线路 | 主题游线、天数里程与点位组合 |
| 红迹故事 | 数字故事正文、封面、音频与 AR 素材 |
| 红文创商品 | 文创与助农商品、价格库存、故事卡、DIY 定制开关、承接农户 |
| 合作农户 | 农户与合作社信息、帮扶项目与进度 |
| 研学任务 | 打卡任务、类型与积分 |

## 新增模块的方法

后台采用元数据驱动：在 `src/config.js` 的 `resources` 中新增一项（列表列 `listColumns` 与表单字段 `fields`），并在 `backend/red_admin.go` 的 `adminResources()` 里注册同名资源与数据表字段即可，无需新写页面。

字段类型支持：`text`、`textarea`、`number`、`select`、`ref`（引用其他资源）、`image`（上传）、`list`（每行一条）、`bool`。

## 本地开发与构建

```powershell
cd admin
npm install
npm run dev     # 开发模式，访问 http://127.0.0.1:5174/admin/
npm run build   # 构建到 dist，由后端在 /admin/ 托管
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `ADMIN_USER` | `hjw` | 管理员账号 |
| `ADMIN_PASSWORD` | `123456` | 管理员密码 |
| `ADMIN_SECRET` | 内置字符串 | 登录令牌签名密钥，生产环境建议修改 |
